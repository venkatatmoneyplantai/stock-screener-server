# Context

Disposable scratch space for agents working in this repo — notes,
in-progress reasoning, things worth remembering for the rest of a session.

This file is **not** canonical. Nothing here should be treated as settled
guidance — architecture and product decisions belong in `_docs/DECISIONS.md`,
current implementation state belongs in `_docs/current-status.md`, and
planned work belongs in `_docs/TODO.md`. Content here can be cleared or
overwritten at any time.
